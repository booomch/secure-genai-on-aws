05 / Takeaways

Defense is a chain, not a checkbox.

Prevent Before inference

  • Keep system instructions separate from user content
  • Validate type, size, encoding, and known attack patterns
  • Review RAG sources, tools, plugins, and skill files
  • Apply Guardrails to both model input and output

Contain Assume bypass

  • Scope IAM to approved models and required actions
  • Require confirmation for destructive or external tools
  • Keep secrets outside model context and retrieval results
  • Rate-limit abusive clients at WAF and API Gateway

Detect Measure decisions

  • Track block rates by layer and attack category
  • Use synthetic canaries to detect prompt disclosure
  • Alert on sudden Guardrail interventions or tool failures
  • Log request IDs and decisions, never raw sensitive prompts

Respond Recover safely

  • Disable affected tools, skills, or data sources quickly
  • Rotate exposed credentials and review CloudTrail activity
  • Add every confirmed attack to regression tests
  • Re-enable capabilities gradually with tighter permissions

Design principle: treat model output as untrusted until deterministic controls authorize the next action.
